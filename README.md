# Cornerpin

A multi-tenant PWA for selling subdivision lots. Owners manage subdivisions, phases and lots;
buyers browse a map, see price and status, view photos and documents, save lots and get
notified when something changes.

Status: planning. Nothing is built yet.

- Plan: [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md)
- Decisions: [DECISIONS.md](DECISIONS.md)
- Working rules for Claude Code: [CLAUDE.md](CLAUDE.md)

Stack: FastAPI, Postgres + PostGIS, Next.js, REST + GraphQL, Cloud Run, Neon.

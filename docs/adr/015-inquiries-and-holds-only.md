# ADR-015: Inquiries and hold requests only in v1

- **Status:** Accepted
- **Date:** 2026-10-01
- **Applies from:** P1-08

## Context

Buyers need a way to express interest in a lot. Scott is open to taking deposits either way.

## Decision

v1 lets a buyer inquire or request a hold, which the owner approves. No money moves online.

## Consequences

- No payment provider and no refund handling.
- A deposit flow would be a new ADR.
